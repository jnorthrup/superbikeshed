## Directory Structure

```

├── gemini/             # Gemini-specific compliance framework
```

## Usage

### For Claude
Copy `.llm/pristine/claude/CLAUDE.md` to your project root as `CLAUDE.md`

### For Gemini CLI
Copy `.llm/pristine/gemini/GEMINI.md` to your project root as `.gemini.md`

### For Cursor
Copy `.llm/pristine/cursor/CURSOR.md` to your project root as `.cursorrules`

### For Aider
Copy `.llm/pristine/aider/AIDER.md` to your project root as `.aider.md`
