    feat: Create TrikeshedMinimalJson KMP project for serialization
    
    This commit introduces the `TrikeshedMinimalJson` project, a Kotlin
    Multiplatform (KMP) library designed to specify and demonstrate
    JSON serialization for core Trikeshed data structures using
    `kotlinx.serialization`.
    
    Key features:
    - Defines KMP-compatible data classes: `DealProxy`, `VendorProxy`,
      and `CouchTxProxy` in `commonMain`.
    - Implements custom serializers for `DealProxy` and `VendorProxy` to
      handle `_id` mapping, conditional `id` serialization, and a `type`
      discriminator field, aligning with specified requirements.
    - `CouchTxProxy` uses default `kotlinx.serialization`.
    - Configures `kotlinx.serialization.json.Json` (as `AppJson`) with
      `prettyPrint = false` and `encodeDefaults = false`.
    - The project structure is based on the main Trikeshed KMP setup,
      targeting JVM, JS, WasmJS, and Native platforms (Kotlin 2.0.0,
      kotlinx.serialization 1.6.3).
    - Includes comprehensive unit tests in `commonTest` for serialization
      and deserialization logic, all passing on the JVM target.
    - Provides a `README.md` detailing the project's purpose, structure,
      and usage.
    
    This project serves as a reference for JSON interaction with these
    Trikeshed types.
