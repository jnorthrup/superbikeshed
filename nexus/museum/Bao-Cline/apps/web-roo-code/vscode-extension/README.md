# Bao Cline VSCode Extension

AI-powered development assistant with command-line aider integration.

## Features

- **Generate Code**: AI-powered code generation with context awareness
- **Aider Integration**: Direct command-line aider access from VSCode
- **Quick Access**: Keyboard shortcuts for rapid development
- **Web Integration**: Quick access to the Bao Cline web application

## Usage

### Generate Code

1. Select code in your editor
2. Press `Ctrl+Shift+R` (or `Cmd+Shift+R` on Mac)
3. Enter your prompt describing what you want to generate
4. Choose how to apply the generated code

### Aider Command Mode

1. Press `Ctrl+Shift+A` (or `Cmd+Shift+A` on Mac)
2. Enter aider command (without 'aider' prefix)
3. Command runs in integrated terminal

### Commands

- `Bao Cline: Generate Code` - Generate code based on selection and prompt
- `Bao Cline: Aider Command Mode` - Run aider commands directly
- `Bao Cline: Open Web App` - Open the Bao Cline web application

## Requirements

- Visual Studio Code 1.74.0 or higher
- Internet connection for AI code generation
- Optional: aider-chat for command-line integration

## Installation

Install from VSIX file or VSCode marketplace.
