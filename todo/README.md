## Usage Guidelines

### For New Items
1. Add to MASTER_TODO.md with appropriate status and priority
2. For component-specific details, add to relevant component file
3. For QUICDB items, add directly to quicdb_todo_lockdown.md

### For Status Updates
1. Update status in MASTER_TODO.md
2. Update corresponding component file if detailed work is involved
3. Maintain cross-references between files

### For Migrations
1. Mark items as "MIGRATED TO [filename]" in MASTER_TODO.md
2. Ensure target file has proper consolidation rules
3. Update this README with migration status
